# Security Policy

## Supported Versions

Security updates are provided for the latest stable release of Numerals.

| Version | Supported |
| ------- | --------- |
| Latest Release | ✅ Yes |
| Older Releases | ❌ No |
| Development Builds | ❌ No |

## Reporting a Vulnerability

If you discover a security vulnerability in Numerals, please report it privately through GitHub's security reporting feature.

### How to Report

1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Provide a detailed description of the issue, including:
   - Steps to reproduce the vulnerability
   - Potential impact
   - A proof of concept (if applicable)
   - Your environment (operating system, application version, etc.)

Please **do not disclose security vulnerabilities publicly** until they have been reviewed and addressed.

## What to Expect

After a report is submitted:

- We will acknowledge receipt as soon as reasonably possible.
- We will investigate the report.
- If the issue is confirmed, we will work on a fix and coordinate responsible disclosure.
- Once a fix is available, a security advisory may be published through GitHub.

## Scope

This policy applies to:

- The Numerals desktop application
- Official source code contained in this repository
- Official releases published by the project

Third-party libraries and dependencies maintain their own security policies and disclosure processes.

## Security Best Practices

Users should:

- Download Numerals only from official releases.
- Keep the application up to date.
- Avoid running modified or untrusted builds.
- Report suspected security issues responsibly.

## Disclosure Policy

We appreciate responsible disclosure and ask that security researchers give us reasonable time to investigate and resolve reported issues before publicly discussing them.

Thank you for helping keep Numerals secure.
