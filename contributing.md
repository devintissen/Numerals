# Contributing to Numerals

Thank you for your interest in contributing to **Numerals**! Contributions of all kinds are welcome, including bug reports, feature suggestions, documentation improvements, and code changes.

## Project Philosophy

Numerals is designed to provide a clean, fast, and distraction-free calculator experience. When contributing, please strive to preserve the application's simplicity, consistency, and performance. Features should enhance the user experience without introducing unnecessary complexity.

Before contributing, please take a moment to read the guidelines below.

---

# Getting Started

## Prerequisites

Before running Numerals locally, ensure you have the following installed:

* Node.js
* npm
* A supported operating system

You can verify your installation by running:

```bash
node --version
npm --version
```

## Setting Up the Development Environment

1. Fork the repository on GitHub.

2. Clone your fork:

```bash
git clone https://github.com/your-username/numerals.git
```

3. Navigate to the project directory:

```bash
cd numerals
```

4. Install the project dependencies:

```bash
npm install
```

5. Start the development version:

```bash
npm start
```

# Reporting Bugs

If you encounter a bug or unexpected behavior, please create a GitHub Issue and include as much information as possible.

A helpful bug report should include:

* Operating system and version
* Numerals version
* Steps to reproduce the issue
* Expected behavior
* Actual behavior
* Screenshots or recordings (if applicable)

---

# Suggesting Features

Feature requests are always welcome.

Before implementing a major feature or significant architectural change, please open a GitHub Issue to discuss the idea first. This helps ensure that new features align with the goals and design philosophy of Numerals before development begins.

When suggesting a feature, please include:

* What problem does the feature solve?
* How would it improve the user experience?
* Any examples or references that may help explain the idea.

---

# Making Changes

When contributing code, please:

* Keep changes focused and avoid unrelated modifications.
* Follow the existing code style and formatting.
* Test your changes before submitting a pull request.
* Update documentation if your changes affect how Numerals is used.
* Avoid introducing unnecessary dependencies whenever possible.

---

# Pull Requests

When submitting a pull request:

* Ensure your branch is up to date with the `main` branch.
* Keep your pull request focused on a single feature, improvement, or bug fix whenever possible.
* Provide a clear description of what you changed and why.
* Include screenshots for user interface changes when applicable.
* Confirm that the application builds and runs correctly before submitting.

A good pull request should clearly explain:

* What was changed?
* Why was it changed?
* How was it tested?

---

# Development Guidelines

Please help maintain the design philosophy of Numerals by following these principles:

* Keep the user interface simple, intuitive, and consistent.
* Prioritize performance and reliability.
* Avoid unnecessary dependencies.
* Follow Electron security best practices.
* Write clean, readable, and maintainable code.
* Preserve the clean and minimal design philosophy of Numerals.

---

# Code of Conduct

Please be respectful and constructive when interacting with other contributors.

Harassment, discrimination, or inappropriate behavior will not be tolerated.

Thank you for helping make Numerals better!
